# Documentación exclusiva AdministraNET (VB6)

Los archivos `.md` en esta carpeta se etiquetan como **sistema = administranet** cuando Synap expone el conocimiento para el RAG del módulo Support. El resto de la documentación bajo `docs/` se etiqueta como **synap**.

**Uso:** Colocar aquí la documentación que describe solo AdministraNET (VB6): procedimientos, tablas VB6, menú Archivo, migración desde VB6, etc. Así el copiloto en Support puede filtrar por "AdministraNET (VB6)" y responder consultas funcionales usando solo este contenido.

Ver [../README.md](../README.md) para la estructura general de `docs/` y [support/docs/RAG_Y_SYNAP.md](../../support/docs/RAG_Y_SYNAP.md) para el flujo RAG y actualización.
