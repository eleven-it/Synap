# Convenciones UX/UI (Synap)

## Navegación lista → detalle

Cuando el usuario pasa de una **tabla o listado** a **datos específicos** (edición, ficha, detalle):

1. **CTA "Volver a [entidad]"**  
   Incluir arriba del contenido un enlace claro para volver al listado (misma entidad). Ejemplo: "← Volver a sucursales" en el formulario de edición de sucursal. Mejora la experiencia al no depender solo del menú o del navegador.

2. **Título con contexto**  
   En pantallas de edición, mostrar el **nombre del ítem** que se está editando junto al título (ej. "Editar Sucursal **Casa Matriz**"), con el mismo color que el botón de acción principal (p. ej. púrpura del botón Guardar) para coherencia visual.

Estas convenciones se aplican de forma consistente en todas las vistas de tipo listado → formulario/detalle (sucursales, empresas, usuarios, etc.).
