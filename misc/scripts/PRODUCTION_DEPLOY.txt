MÉTODO 3: CLONAR SOLO LO NECESARIO (FRESH INSTALL)
=================================================================

1. Conectarse al servidor:
   ssh -p 38001 sparedes@198.27.68.214

2. Hacer backup de .env y media:
   cp /home/sparedes/Synap/.env /tmp/synap.env.backup
   tar -czf /tmp/synap_media_backup.tar.gz /home/sparedes/Synap/media/

3. Eliminar instalación anterior:
   rm -rf /home/sparedes/Synap

4. Clonar repositorio con sparse-checkout:
   git clone -b 1.0 --depth 1 --filter=blob:none \
     git@github.com:eleven-it/Synap.git /home/sparedes/Synap
   
   cd /home/sparedes/Synap
   
   # Configurar sparse-checkout para excluir archivos innecesarios
   git sparse-checkout init --cone
   git sparse-checkout set \
     core \
     django_project \
     theme \
     finance \
     inventory \
     sales \
     purchases \
     logistics \
     tiendanube \
     tiendanube_administranet \
     support_ai \
     static \
     templates \
     locale

5. Restaurar .env y media:
   cp /tmp/synap.env.backup .env
   tar -xzf /tmp/synap_media_backup.tar.gz -C .

6. Iniciar servicios:
   docker-compose up -d --build
   docker exec Synap_app python manage.py migrate

MANTENIMIENTO PERIÓDICO
=================================================================

Ejecutar cada mes:

1. Limpiar Docker:
   sudo docker system prune -af

2. Limpiar logs antiguos:
   find /home/sparedes/Synap/logs -name "*.log" -mtime +30 -delete

3. Verificar espacio:
   df -h /

4. Limpiar cache de Git:
   cd /home/sparedes/Synap
   git gc --aggressive --prune=now

=================================================================
TROUBLESHOOTING
=================================================================

Problema: "No space left on device"
Solución:
  1. sudo docker system prune -af
  2. sudo apt clean && sudo apt autoremove
  3. bash misc/scripts/clean_production_server.sh

Problema: "Git GC fails"
Solución:
  - Requiere espacio temporal. Limpiar Docker primero.
  - O desactivar: git config gc.auto 0

Problema: "Permission denied"
Solución:
  - Verificar permisos: ls -la /home/sparedes/Synap
  - Ajustar: sudo chown -R sparedes:sparedes /home/sparedes/Synap
