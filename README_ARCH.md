# Arquitectura del Proyecto Synap

- Aplicación Django containerizada con Docker
- Base de datos MySQL compartida con AdministraNET (VB6)
- Normalización de tipos de datos vía `core.utils.administranet_types`
- Flujo de ramas y despliegue documentado en `docs/general/`
- Tests y comandos ejecutados dentro del contenedor `Synap_app`
