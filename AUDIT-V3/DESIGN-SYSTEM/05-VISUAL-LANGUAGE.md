# 05 — Visual Language

**Estado:** COMPLETE | Current state — no rebrand

| Dimension | Current Synap |
|-----------|---------------|
| **Density** | High in operational (MPR, stock); medium in admin |
| **Hierarchy** | Hero headers (reports) + table-first elsewhere |
| **Brand** | Purple-blue gradient, Synap + AdministraNET logos |
| **Contrast** | Dark hero + light content areas |
| **Color use** | Purple = primary action; emerald/red status |
| **Icons** | Material Icons outlined |
| **Cards** | rounded-xl white on slate-50 bg |
| **Shadows** | Subtle elevation on cards/modals |
| **Whitespace** | Compact in tables; generous in marketing heroes |
| **Typography hierarchy** | text-sm dense tables; text-2xl page titles |

## Principles (evidence-based, not aesthetic)

1. **Clarity over decoration** — operarios need scanability
2. **Density is a feature** in ERP tables
3. **Purple = Synap action** — already learned by users
4. **Dark hero = analytics context** — reports pattern

No new branding in V3 — document current language for normalization.
